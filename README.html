VentureLink

Application Next.js / TypeScript connectée à Supabase.

Lancement local Node.js

  1. Copier .env.local.example vers .env.local.
  2. Renseigner l’URL Supabase et la clé publishable.
  3. Exécuter npm ci.
  4. Exécuter npm run dev.

Lancement avec Docker Compose

  1. Copier .env.docker.example vers .env.
  2. Renseigner NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY.
  3. Construire et démarrer avec docker compose up -d --build.
  4. Ouvrir http://localhost:3000.
cp .env.docker.example .env
docker compose up -d --build
docker compose ps
docker compose logs -f venturelink

Les variables NEXT_PUBLIC_* sont utilisées au build Next.js et à l’exécution. Si l’URL Supabase ou la clé publishable change, reconstruire l’image avec docker compose up -d --build.

Architecture Docker

Le conteneur embarque uniquement l’application Next.js en sortie standalone. Supabase reste hébergé dans le projet Cloud existant : Auth, PostgreSQL, Storage et RLS ne sont donc pas dupliqués localement.

Sécurité

Ne jamais mettre de clé service_role ou de clé sb_secret_* dans une variable NEXT_PUBLIC_*. Le conteneur s’exécute avec un utilisateur non-root.

État

Consulter STATUS.html pour l’état technique du projet.
