VentureLink — application v0.3

Base Next.js / TypeScript connectée à Supabase. Le prototype HTML V8 reste disponible dans reference/ uniquement comme référence visuelle.

Lancement local

  1. Copier .env.local.example vers .env.local.
  2. Renseigner l’URL Supabase et la clé publishable.
  3. Exécuter npm install.
  4. Exécuter npm run dev.

Sécurité

Ne jamais mettre de clé service_role ou de clé secrète Supabase dans une variable NEXT_PUBLIC_*. La Data Room utilise un bucket privé et la RLS.

État

Consulter STATUS.html pour l’état exact de l’implémentation et les contrôles restant avant production.
